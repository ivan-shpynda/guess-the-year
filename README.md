# Вгадай рік

Невелика вікторина на Vue 3: користувачу показують історичну подію, а він за допомогою слайдера намагається вгадати рік, коли вона відбулась. Чим більше відхилення від правильної відповіді — тим більше втрачається "життів".

## Як грати

1. Прочитай подію на картці.
2. Обери рік за допомогою слайдера або поля вводу.
3. Натисни **ПІДТВЕРДИТИ**, щоб побачити правильну відповідь і відхилення.
4. Натисни **НАСТУПНЕ ПИТАННЯ**, щоб перейти далі (слайдер зберігає останній обраний рік як стартову позицію).
5. Гра закінчується, коли закінчуються життя — після цього можна почати заново.

## Стек

- [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- [Vite](https://vitejs.dev/) для збірки та дев-сервера
- [Motion](https://motion.dev/) для анімацій
- CSS Modules зі спільними CSS-змінними (кольори винесені в `:root` у `src/App.vue`)

## Структура проєкту

```
src/
  App.vue                    # головний компонент, стан гри
  main.js                    # точка входу
  data/questions.json        # список подій та років
  components/
    PageHeader.vue           # шапка сторінки (автор, посилання)
    GameHeader.vue           # плашки "життя" / "питання"
    QuestionCard.vue         # картка з описом події
    YearSlider.vue           # слайдер + поле вводу року, стан відповіді
    GameOver.vue             # екран завершення гри
```

## Розробка

```bash
npm install
npm run dev       # дев-сервер з гарячим перезавантаженням
npm run build     # продакшн-збірка у dist/
npm run preview   # перегляд продакшн-збірки локально
```
